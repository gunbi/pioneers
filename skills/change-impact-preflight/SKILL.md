# 变更影响面预检

[English edition](SKILL.en.md)

1. 确认目标工作区、分支、基线提交和待改范围。查看未提交改动与现有调用方。记录适合当前变更的最小验证命令，区分已知基线失败和本次新出现的失败。保留现场。
2. 对照旧版逐项检查接口字段、错误码、默认值和数据语义。用调用点、契约、配置或运行记录说明受影响的版本和调用方。涉及开关时记录默认值、启用身份和灰度范围。用可复跑的对照验证关闭时的行为。
3. 按实际风险核对旧格式、需要回填的数据范围、新旧版本共存、双写失败与对账。若触及共享资源、权限或路由，核对资源归属、各阶段的实际执行身份和故障影响。为适用的新旧读写组合分别写验证用例。
4. 写明回滚动作、触发条件和回滚后的数据状态。需要补偿、对账或重放时，说明处理方式和验证结果。标记回滚是否已演练。
5. 输出简短结论，包含基线、受影响方、验证命令或证据、回滚条件，以及仍待确认的风险。共享契约、旧数据、并行写入、共享资源、权限和回滚风险交 LD 协调，由 QA 独立验收。只有范围局部、无上述风险且能定向复验时，采用小改动流程。
