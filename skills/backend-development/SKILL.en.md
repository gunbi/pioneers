# Backend development

[Chinese edition](SKILL.md)

1. Read the interface contract and existing routes. Follow the project's validation and error-response conventions.
2. Implement server behavior and cover the success path, invalid input and relevant boundary cases in the contract.
3. If the project has an OpenAPI JSON description, run `backend_api_check` to check the interface description. Run the existing API or integration tests and deliver the changes, test commands and observed results.
