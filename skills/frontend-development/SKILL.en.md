# Frontend development

[Chinese edition](SKILL.md)

1. Read the existing page structure and the interface contract from the handoff. Follow the project's UI component and startup conventions.
2. Implement the main user journey and the failure states that could prevent completion. Preserve keyboard operation, visible focus, input labels and narrow-screen usability.
3. Run `frontend_html_check` on static HTML. Verify actual interactions in a browser and deliver access instructions, check results and unverified items.
