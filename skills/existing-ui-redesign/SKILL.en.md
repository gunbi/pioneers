# Redesign an existing interface

[Chinese edition](SKILL.md)

1. Read the audit of the old version, the approved flow and layout, and the project's existing components, styles and design conventions. List the problems to address, the pages affected and behavior to preserve.
2. Arrange navigation, content and primary actions in the order users make decisions. Reuse existing components and layout patterns first. Adjust spacing, alignment, text hierarchy and grouping to address observed problems. Decide the narrow-screen order for key information and actions before adding visual detail.
3. Make the changes needed to solve the problem in the existing stack. Check existing routes, form state, filters and failure recovery. If an approved interaction, data contract or project convention must change, hand off the impact and design decision first.
4. Rerun key scenarios with the same data and viewport. Record the original problem, revised behavior, remaining limitations and exact version verified. Use screenshots to show layout changes and observed interactions to verify behavior.
