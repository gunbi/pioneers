# 用户旅程地图

1. 选定用户、任务和旅程范围。明确从哪里开始、到什么用户结果结束，以及资料覆盖的是哪些人和阶段。
2. 按用户实际经历排列各阶段。为每个阶段记录用户目标、行为、触点、已观察到的障碍和证据出处。缺少证据时标记假设或未知，并记录验证方式。以材料可支持的范围描述感受和频率。
3. 找出最影响任务完成的断点。优先考虑用户卡住、无法恢复或必须重复工作的地方。对照已有证据说明优先级和不确定性。
4. 交接一份简要旅程表，包含阶段、触点、结果、证据或假设、阻碍和待验证机会。把值得解决的断点交给产品体验设计任务，进一步明确页面动线与验收。
